### 1. Назначение и ключевая особенность проекта
Информационный ресурс предназначен для организации учебного процесса в образовательном учреждении:
- **Преподаватель** создает дисциплины, темы и лекции, загружает теоретические материалы (DOCX, PDF), формирует контрольные вопросы и проверочные тесты (включая вопросы на **сопоставление терминов и определений**), ведёт **электронный академический журнал** успеваемости, формирует и **распечатывает ведомости со списочным составом по каждой лекции**, а также при необходимости вручную открывает доступ или сбрасывает попытки.
- **Студент** изучает материалы по порядку, проходит контрольные вопросы и проверочное тестирование, отслеживает свой прогресс в личном кабинете.

🔒 **Главное функциональное требование (Последовательное открытие лекций):**
Студент не может открыть следующую лекцию, пока не изучит текущую и не сдаст по ней проверочный тест с результатом не менее **70%**.  
Ограничение строго контролируется **на стороне сервера** (сервисом `ProgressionService`): если студент попытается перейти по прямой ссылке на закрытую лекцию (например, `/Lectures/Details/2`), сервер отклоняет запрос и возвращает страницу с предупреждением.

### 1.1. Новые расширенные возможности (по требованиям преподавателя)
1. **Электронный академический журнал успеваемости (`/Teacher/Journal`):**
   - Интерактивная матрица успеваемости: студент × лекции с цветовой индикацией, лучшим баллом, 5-балльной оценкой (Отлично/Хорошо/Удовл/Неуд) и количеством использованных попыток.
   - Сводный подробный реестр-протокол: *Студент — Учебная группа — Лекция — Статус доступа — Балл (%) — Оценка — Число попыток — Дата активности — Итог зачёта*.
   - Кнопка **«Распечатать журнал»** со специализированными CSS-стилями `@media print` под формат А4 и блоком подписи преподавателя Парван Е.Н.
2. **Списочный состав и ведомость прохождения каждой лекции (`/Teacher/LectureRoster`):**
   - Возможность из любой лекции открыть официальную ведомость со списочным составом всех записанных студентов.
   - Фильтрация по учебным группам, процент сдачи (Pass Rate), фиксация точной даты сдачи и количества попыток.
   - Функция быстрой печати ведомости с реквизитами дисциплины и местом подписи преподавателя.
3. **Вопросы на сопоставление понятий и их расшифровок (Matching):**
   - Поддержка создания вопросов типа «Сопоставление» в редакторе тестов (пары: термин ➔ определение).
   - Студенту определения предлагаются в перемешанном виде через динамические выпадающие списки.
   - Детальный разбор результатов после прохождения теста: таблица сопоставлений с подсветкой правильных и ошибочных пар.

### 4. База данных PostgreSQL (`PR3`)
- **Имя БД:** `PR3` (хост: `127.0.0.1:5432`).
- Приложение использует Entity Framework Core Code-First (`context.Database.EnsureCreatedAsync()`).
- В корне репозитория также сохранен полный SQL-дамп: **`init_database.sql`** (можно импортировать в pgAdmin 4 или DBeaver).
- **Таблицы БД (14 шт.):**
  `Users`, `StudentGroups`, `GroupMemberships`, `Disciplines`, `Topics`, `Lectures`, `ControlQuestions`, `Tests`, `TestQuestions`, `AnswerOptions`, `TestAttempts`, `StudentAnswers`, `LectureProgress`, `AuditLogs`.

### 5. Инструкция по запуску проекта в Visual Studio

1. Открыть решение **`EduCabinet.sln`** в **Visual Studio 2022** (или открыть терминал в папке `EduCabinet`).
2. Убедиться, что служба PostgreSQL запущена (БД `PR3` на порту 5432).
3. При необходимости скорректировать пароль подключения в `appsettings.json`:
   ```json
   "ConnectionStrings": {
     "DefaultConnection": "Host=localhost;Port=5432;Database=PR3;Username=postgres;Password=postgres;"
   }
   ```
4. Нажать клавишу **F5** (или ввести в терминале `dotnet run`).
5. Браузер откроет адрес: `http://localhost:5076` (или `https://localhost:7147`).

### 6. Внедрение и доступ по локальной сети (п. 6.3 ТЗ)
Для организации доступа студентов с соседних компьютеров или смартфонов в учебной аудитории:
```powershell
dotnet publish -c Release -o ./publish
cd publish
dotnet EduCabinet.dll --urls "http://0.0.0.0:5000"
```
Студенты подключаются через браузер по IP-адресу преподавателя: `http://192.168.x.x:5000`.  
Порт СУБД PostgreSQL (5432) остается изолирован и защищен брандмауэром.
